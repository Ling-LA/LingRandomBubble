# 0.1.54 验证报告

日期：2026-10-15。版本：0.1.54 / versionCode 55。

## 本次变更

新增被动商城收录：开启原有“自动收录”开关后，浏览 QQ 个性装扮商城或搜索指定气泡，收录本次加载的气泡编号和官方名称。按主编号去重，新条目默认未勾选，已有自定义名称、选择和装扮配置保留。继续支持聊天收录。

HTTP 只观察 zb.vip.qq.com 的已验证首页、分页列表和搜索路径，另支持既有详情与推荐响应；不读取搜索历史，不从 URL 猜编号，不保存凭据或原始网络内容。网络、业务状态及商品类型均须有效；数据大小、解析深度与队列容量受限。账号或收录开关代次改变后拒绝迟到响应。

## 范围与限制

仅收录已经加载并经过已适配响应入口的数据；缓存页面没有新响应时，需重新搜索或重新进入分类。模块不会自动遍历全商城。新增条目不自动加入轮换候选，收录不代表拥有使用权益，实际切换仍由原账号权益检查决定。

本轮未测试其他 QQ 版本、其他加载器、真实切换 QQ 账号、超大商城结果或长时间运行；账号隔离和迟到响应以核心状态测试覆盖。未重新进行群聊/私聊消息发送、接收端气泡或高频轮换验证，历史版本的结果不作为本轮结论。
