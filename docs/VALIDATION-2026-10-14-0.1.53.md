# 0.1.53 验证报告

范围：名称搜索、多关键词搜索、按筛选结果批量选择、清新界面/小方形复选框、同主编号分组显示、收录后自动补全商城名称。目标设备为本会话已连接的 Android 真机，QQ 9.3.50 / LSPatch 集成加载。当前发布号 0.1.53 / code 54。

## 实现

- LibrarySearch 在两个库入口统一执行 NFKC/大小写归一化、空格/中英文逗号/顿号/分号拆词、字面 OR 匹配，名称和主/子编号可混用。显示保留自定义名称，商城 officialName 也是搜索别名。
- 批量操作快照包含当前筛选的全部分页，结果外记录不变；空结果禁用；内嵌撤销恢复同一账号的原选择快照。
- 同一正主编号按一款展示，采集属性或子气泡的原记录保留。零/缺失主编号按原 key 分开。部分勾选用小方框横线表示；组内操作只作用于匹配成员，改名/删除显示记录数，删除另行确认。
- BubbleUi 使用奶白/薄荷配色、固定20dp自绘方形标记和60dp整行触控目标；保留原生 CheckBox 语义。名称/编号分层、独立页码、空结果提示、长按管理；QQ 内嵌设置、装扮配置与独立气泡库共用样式。
- 新收录变体直接继承已有主编号的商城名称。没有缓存时以及旧库缺失时，由现有库同步 worker 扫描名称缺失项，自动排队；不需要打开气泡库面板。主编号去重，单请求，正常成功至少间隔2秒。失败全局冷却60秒，同款5/10/20/30分钟退避。QQ 前台解锁、商城已初始化且装扮请求空闲才启动新查询；查询超时20秒；旧账号/迟到回调不能写入新账号。自动补名不提交账号装扮 SET。
- 名称独立于选择和装扮 generation，在原 worker 合并、原子保存；名称数据变化不设置库选择脏标记。最多64条名称页可用于大库同步，不镜像旧选择覆盖 QQ 大库。查询异常与 QQ 主线程、逐消息/计时切换隔离。

## 实机范围与限制

本轮未发送聊天消息，未重新核对接收端气泡交付；历史52发送/接收证据不能代替53新验证。本轮聚焦库管理与只读名称补全，未重新等待低频轮换周期，也不据短时测试宣称长期稳定或账号风险为零。

收录缓存继承、队列状态和持久化已测试；新未知编号的远端自动名称回包需要有实际缺失名称的收录项，本机250款已缓存，本轮没有自然出现新的未知款式，故“新未知编号收录→网络名称回包”的完整 QQ 现场链路未覆盖。接口未初始化、离线或服务器拒绝时保留编号并等待/重试，不保证收录时同步获得名字。
